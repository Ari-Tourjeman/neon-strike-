# Neon Strike

משחק יריות תלת־ממדי לטלפון בדפדפן. כולל לובי לבחירת שלושה נשקים, גלי רחפנים, קפיצה וכבידה, קירות מוצקים, מבנים עם כניסה, מדרגות וגגות, זכוכיות שבירות ומצב שיתוף פעולה לשני שחקנים.

## הפעלה מקומית

```bash
python3 -m http.server 8000 -d dist
```

לאחר מכן פותחים `http://localhost:8000` בדפדפן. בטלפון מומלץ לשחק לרוחב. במחשב: WASD לתנועה, עכבר לכיוון, לחיצה לירי, R לטעינה ורווח לקפיצה.

התנועה כוללת תאוצה ובלימה, ויש נזק מנפילה מגובה. הכביש והבטון משתמשים במרקמים מצולמים עם מפות נורמל וחספוס. זו עדיין גרסת משחק לדפדפן, ולא גרפיקה פוטוריאליסטית מלאה.

## ירי ושליטה

לחיצה קצרה יורה כדור אחד. החזקה רציפה ברובה הסער ובתת־המקלע יורה כדורים נפרדים לפי קצב האש; רובה הקלעים יורה פעם אחת לכל לחיצה. הירי מחושב ממרכז הכוונת אל המטרה ונבדק שוב מקצה הקנה, כך שקיר או מחסה קרוב חוסם אותו. הכוונת מתרחבת בתנועה ובירי. בטלפון מקישים על **כוונת** כדי להפעיל או לכבות ADS; במחשב מחזיקים לחצן עכבר ימני. ADS מגדיל מעט ומשפר דיוק.

בפתח של כל מחסן יש לוח זכוכית שאפשר לנפץ בירייה. פגיעה יוצרת שבר קצר ורסיסים הנופלים ונעלמים, ואחריה אפשר לירות ולעבור דרך הפתח. מצב הזכוכיות מסונכרן גם בחדר לשני שחקנים. הבזק קנה, תרמילים, קליע חזותי קצר ואפקט פגיעה נוצרים לכל ירייה ונמחקים לאחר זמן קצר כדי להגביל עומס בטלפון.

## מולטי פלייר

בלובי בוחרים **צור חדר**, מעתיקים את הקוד בן שש התווים ושולחים אותו לחבר. החבר בוחר **הצטרף**, מזין את הקוד ולוחץ על כפתור ההצטרפות. המארח יכול להתחיל לפני החיבור. אפשר לבחור נשק בנפרד בכל מכשיר. מצב המשחק הוא שיתוף פעולה נגד גלי הרחפנים; המארח מסנכרן את מיקום הרחפנים, הפגיעות והגלים. אם החיבור נקטע, האורח ממשיך לבדו.

המולטי פלייר משתמש ב־PeerJS 1.5.5 דרך CDN ובשירות האיתות הציבורי של PeerJS. נדרש אינטרנט בשני המכשירים. חיבורי WebRTC עלולים להיכשל ברשתות מסוימות ללא שרת TURN. לא נכללים כאן שרת משחק ייעודי, חשבונות, צ׳אט או משחק מול שחקנים אחרים.
