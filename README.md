# Neon Strike

משחק יריות תלת־ממדי לטלפון בדפדפן. כולל לובי לבחירת שלושה נשקים, גלי רחפנים, קפיצה וכבידה, קירות מוצקים, מבנים עם כניסה, מדרגות וגגות.

## הפעלה מקומית

```bash
python3 -m http.server 8000 -d dist
```

לאחר מכן פותחים `http://localhost:8000` בדפדפן. בטלפון מומלץ לשחק לרוחב. בגרסת מחשב: WASD לתנועה, עכבר לכיוון, לחיצה לירי, R לטעינה ורווח לקפיצה.

הגרפיקה מסוגננת ומשתמשת במרקמים ותאורה בזמן אמת; היא אינה פוטוריאליסטית. `dist/three.module.js` כלול בפרויקט תחת הרישיון שבקובץ `dist/THREE-LICENSE.txt`.
