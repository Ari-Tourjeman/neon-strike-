# Neon Strike

משחק יריות תלת־ממדי לטלפון בדפדפן. כולל לובי לבחירת שלושה נשקים, גלי רחפנים, קפיצה וכבידה, קירות מוצקים, מבנים עם כניסה, מדרגות וגגות.

## הפעלה מקומית

```bash
python3 -m http.server 8000 -d dist
```

לאחר מכן פותחים `http://localhost:8000` בדפדפן. בטלפון מומלץ לשחק לרוחב. במחשב: WASD לתנועה, עכבר לכיוון, לחיצה לירי, R לטעינה ורווח לקפיצה.

התנועה כוללת תאוצה ובלימה, ויש נזק מנפילה מגובה. הכביש והבטון משתמשים במרקמים מצולמים עם מפות נורמל וחספוס. זו עדיין גרסת משחק לדפדפן, ולא גרפיקה פוטוריאליסטית מלאה.

רישיון Three.js: `dist/THREE-LICENSE.txt`. קרדיטים למרקמים: `dist/assets/CREDITS.txt`.
